# 可爱通缉令 · 邪恶面剂子出没档案

## 怎么打开

从仓库根目录启动本地静态服务器：

```sh
python -m http.server 8080 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8080/mianjizi-wanted/`，用完按 Ctrl+C 关闭。通过 HTTP 打开可使用海报导出。

## 怎么玩

- 点击左下角的小照片切换至下一条；用「上一条」「随机抓拍」或键盘左右方向键也能换照片
- 点主照放大；在「全部档案」里搜索标题或小票里的文字
- 点击「盖章」会在当前照片留下盖章记录；音效默认关闭，右上角可打开
- 「导出通缉海报」保存当前照片、小票和印章组成的 2560×1600 PNG

## 怎么加照片

1. 把照片放进 `photos/`，也可建子文件夹分类。支持 JPG、JPEG、PNG、WebP、AVIF、GIF。使用网页尺寸副本。需要遮住的号码、地址、证件或二维码，可在生成副本前局部遮挡。去除 EXIF、GPS 等元数据。本版 WebP 照片长边不超过 1200 像素。
2. 在源码目录运行 `node scripts/sync-photos.mjs`，刷新网页。脚本不需要 npm 依赖。保留已有照片的顺序和手写字段；新增照片按文件名自然排序并追加到末尾，移走的照片会从清单中删去。想调顺序，在 `photos.js` 移动整条记录。
3. 在 `photos.js` 修改每条数据。用双引号，最后一项后不留多余逗号。建议每张写 3–4 条短小票，方便手机显示。
   - `title` 是档案标题，`crimes` 是小票条目，每条填 `text` 和数字 `count`
   - `total` 是小票合计文案，`stamp` 是印章文案
   - `pos` 是裁切的中心位置，例如 `"50% 24%"` 表示横向居中、纵向偏上；`zoom` 是额外放大倍数，`1` 不额外放大
4. 照片多了，可在 `photos/thumbnails/` 放同名缩略图，再运行同步脚本。同名可以不同扩展名，子文件夹位置要对得上。例如 `photos/日常/01.jpg` 配 `photos/thumbnails/日常/01.webp`。已有手写 `thumb` 字段会保留；换缩略图文件名时记得调整该字段。

清单里的 `pos` 和 `zoom` 只控制页面及海报中的取景。需要遮挡的细节须直接处理在网页图片副本里。
